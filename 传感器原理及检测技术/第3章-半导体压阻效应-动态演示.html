本章要点

    ② 微观机制 ＋ 硅膜片全桥（成对显示）

    微观机制 应力 → 晶格变形 → 散射变化 → 迁移率 μ_c → 电阻率 ρ

    输出读数：晶格间距 · 迁移率 · 电阻率
    紫色圆点＝载流子，紫色虚线圈＝它被晶格散射一次（撞一下、失去定向速度）：散射越频繁 → 漂移越慢 → 迁移率越小 → 电阻率越大。这就是“应力让晶格变形之后，宏观上量到 ρ 变化”的全过程。

    应用：硅膜片压阻全桥 扩散电阻两拉两压，接成全桥，U₀ = E·ΔR/R

    被测压力 P
    膜片边缘应变 ∝ P     0.00 MPa
    输出读数：压力 → 边缘应变 → ΔR/R → 全桥输出 U₀
    U₀ = E·(ΔR/R)：E = 5 V，硅 P 型轻掺杂 K = 1+2μ+πE = 101.8；1.00 MPa → ε = 400 με → ΔR/R = 4.072% → U₀ = 203.6 mV。

    公式推导 金属应变片：几何形变主导

    灵敏度对比 ΔR/R–ε：半导体比金属大 1～2 个数量级

    金属应变片（K = 1.60） 半导体硅 P 型（K = 101.8） 同为 300 με：金属 0.048 %　半导体 3.054 %（约 64 倍）
    纵轴量程随所选半导体材料的 |K| 自动调整：金属曲线几乎贴在横轴上（K ≈ 1.6），半导体 K ≈ 50~100 —— 这就是压阻式传感器输出常常不必放大的原因。
    参数（教材 3.2.1 节量级）：金属应变片（康铜）π ≈ 0、E = 2.00×10¹¹ N/m²、μ = 0.30（K = 1+2μ ≈ 1.6）；半导体硅 πP = 60×10⁻¹¹ m²/N、πN = −100×10⁻¹¹ m²/N，锗 π = 50×10⁻¹¹ m²/N；硅 E = 1.67×10¹¹ N/m²（锗 1.30×10¹¹）、μ = 0.30；掺杂轻/中/重：π ×1.00 / ×0.75 / ×0.50。全桥：恒压源 E = 5 V，1 MPa ≈ 膜片边缘应变 400 με。关系式：σ = Eε，dρ/ρ = πσ = πEε（式 3-34）；dR/R = (1+2μ+πE)ε = Kε（式 3-35）；半导体 πE ≫ 1+2μ → dR/R ≈ dρ/ρ = πEε（式 3-36）；ρ = 1/(nqμ_c)；全桥 U₀ = E·ΔR/R。课堂提问：① 为什么金属应变片的 K 只有 1.5~2.0，而半导体能到 50~100？② 半导体的 ρ 为什么会随应力变化？③ 压阻式压力传感器的输出为什么常常不需要放大？
