    参数：石英 d₁₁ = 2.31×10⁻¹² C/N、εᵣ = 4.6、T_c = 573 ℃，晶片 l/h = 20 mm/5 mm = 4；BaTiO₃ d₃₃ = 190 pC/N；PZT d₃₃ = 250 pC/N（PZT 系 200~500）；PVDF d₃₁ = 6.7 pC/N；C_a = 1000 pF、C_c = 50~1000 pF、C_i = 100 pF、R_a = 10¹⁰ Ω、R_i = 10¹² Ω；电荷放大器 C_f = 1000 pF、R_f = 10¹² Ω；加速度计 m = 2 g、d₃₃ = 250 pC/N → S_q = 4.90 pC/g、C_f = 10 pF → S_v ≈ 490 mV/g、f₀ = 55 kHz。关系式：纵向 q = d₁₁F；横向 q = −d₁₁(l/h)F（d₁₂ = −d₁₁）；q = d₃₃F；U = q/C_a；并联 2q/2C_a/U、串联 q/(C_a/2)/2U；U_i = d₁₁F·jωR/[1+jωR(C+C_a)]；K_u = d₁₁/(C_a+C_c+C_i)；ω_L = 1/[(R_a∥R_i)(C_a+C_c+C_i)]；U_o ≈ −Q/C_f；f_c = 1/(2πR_fC_f)；加速度计 q = d₃₃ma。典型应用：压电加速度计（中心压缩式，q = d₃₃ma、S_v = 490 mV/g）、测力传感器（YDS-781，d₁₁ + 两片并联，可测 5000 N、分辨力 0.001 N）、双向/三向力传感器、玻璃破碎报警器、超声换能器（逆压电效应发射、正压电效应接收）、STM 微位移。课堂提问：① 为什么压电式不能测静态力，加大 R_i 有用吗？② 石英沿 x 与沿 y 受力，电荷量与极性各有什么不同？③ 接电荷放大器时，串联接法的总电荷变不变？
