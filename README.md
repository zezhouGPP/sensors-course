# 传感器原理及检测技术 · 课件演示

《传感器原理及检测技术》课程配套的交互式课件（单文件 HTML，离线可用，无需安装任何环境）。

## 内容

**第 3 章 电阻式传感器 —— 电桥补偿法与三种接法**

- 电路原理图（等臂电桥，四臂实时显示阻值与 ΔR/R）
- 应变片粘贴位置（悬臂梁：上表面受拉、下表面受压，单臂 / 双臂 / 全桥自动切换）
- 接法与输入量：桥臂接法、温度 ΔT、应变 ε、补偿片位置、演示速度
- 原理讲解：教材式 (3-17) ～ (3-21) 按当前参数逐步代入，含灵敏度对比表
- 输出特性曲线：U₀–ΔT（温度补偿）与 U₀–ε（灵敏度与线性度）两个页签
- 输出读数：U₀、温度分量、应变分量、非线性误差、折算虚假应变

## 四个演示

| 按钮 | 内容 |
|---|---|
| ▶ 单臂演示 | 加应变 → 升温 → 省掉补偿片（出现温度误差）→ 改接相对桥臂（误差加倍）→ 回到相邻桥臂 |
| ▶ 双臂演示 | 差动接法灵敏度 ×2；两片同温自动抵消温度；与单臂不补偿做对照 |
| ▶ 全桥演示 | 灵敏度 ×4、严格线性、升温不变、加载到 1000 με 线性加倍 |
| ▶ 三接法对比 | 同一应变下依次切换单臂 / 双臂 / 全桥并升温比较 |

演示速度可用滑块在 0.4× ～ 2.5× 之间调节，运行中拖动立即生效。

## 参数说明

等臂电桥 R₀ = 350 Ω，灵敏系数 k = 2.0，总温度系数 α ≈ 4×10⁻⁵ /℃（相当于 20 με/℃ 的虚假应变），
电源 E = 5.0 V；工作片 ΔR/R = αΔT ± kε（受拉取 ＋，受压取 −），补偿片 ΔR/R = αΔT。

参数集中在 HTML 文件开头的 `var CFG = {...}` 一行，可按需修改。
