## 一、电桥补偿法与三种接法

## 二、半导体材料的压阻效应

**第 3 章 3.2.1 压阻式传感器的工作原理**

- 微观机制动画：应力 → 晶格变形 → 载流子迁移率变化 → 电阻率变化（ρ = 1/(nqμ_c)）
- 公式推导：式(3-34) dρ/ρ = πσ = πEε、式(3-35) dR/R = (1+2μ+πE)ε = Kε、式(3-36) 半导体近似 dR/R ≈ dρ/ρ
- K 的构成对比条：几何效应 1+2μ（金属主导）vs 压阻效应 πE（半导体主导）
- 材料库：金属（π≈0）、硅 P 型（π=60×10⁻¹¹）、硅 N 型（π=−100×10⁻¹¹）、锗；可调 π、μ、掺杂浓度
- ΔR/R–ε 对比曲线：同一应变下半导体比金属大 1～2 个数量级
- 应用：硅膜片压阻全桥，压力 → 边缘应变 → ΔR/R → U₀ = E·ΔR/R（满量程约 200 mV）

## 四个演示

| 按钮 | 内容 |
|---|---|
| ▶ 单臂演示 | 加应变 → 升温 → 省掉补偿片（出现温度误差）→ 改接相对桥臂（误差加倍）→ 回到相邻桥臂 |
| ▶ 双臂演示 | 差动接法灵敏度 ×2；两片同温自动抵消温度；与单臂不补偿做对照 |
| ▶ 全桥演示 | 灵敏度 ×4、严格线性、升温不变、加载到 1000 με 线性加倍 |
| ▶ 三接法对比 | 同一应变下依次切换单臂 / 双臂 / 全桥并升温比较 |

演示速度可用滑块在 0.4× ～ 2.5× 之间调节，运行中拖动立即生效。

## 参数说明

等臂电桥 R₀ = 350 Ω，灵敏系数 k = 2.0，总温度系数 α ≈ 4×10⁻⁵ /℃（相当于 20 με/℃ 的虚假应变），
电源 E = 5.0 V；工作片 ΔR/R = αΔT ± kε（受拉取 ＋，受压取 −），补偿片 ΔR/R = αΔT。

参数集中在 HTML 文件开头的 `var CFG = {...}` 一行，可按需修改。
